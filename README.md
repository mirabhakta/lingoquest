# LingoQuest

**An ADHD-friendly language-learning mystery RPG.**

LingoQuest is an interactive, story-driven game that turns language learning into a mystery adventure. Instead of completing isolated vocabulary drills, players learn by investigating clues, interacting with characters, solving puzzles, and making decisions that shape the story.

## The Idea

What if learning a new language felt more like playing a mystery RPG than studying?

LingoQuest explores that idea by integrating vocabulary, reading comprehension, and language challenges directly into gameplay.

## Planned Features

- Branching mystery narratives with player-driven choices
- Language-learning puzzles integrated into the storyline
- Short, ADHD-friendly gameplay sessions
- XP, achievements, and visual progress tracking
- Hints, retries, and low-pressure learning
- Focus mode to minimize distractions
- Automatic progress saving

## Planned Tech Stack

- **Frontend:** Next.js, TypeScript, Tailwind CSS
- **Backend:** Next.js API routes
- **Database:** Prisma with a database to be finalized
- **Authentication:** Auth.js
- **State Management:** Zustand
- **Testing:** Vitest, Playwright

## Project Status

🚧 **Planning / Pre-development**

Currently working on the game mechanics, architecture, and initial gameplay experience.

## Long-Term Vision

Build a language-learning experience where the story motivates players to keep learning, and language comprehension becomes part of how they uncover mysteries.

The goal is to make learning feel less like a chore and more like an adventure.
